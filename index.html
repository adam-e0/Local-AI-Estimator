How this is calculated

A transparent estimate, not a benchmark guarantee.

Score

Base scores are the Artificial Analysis Intelligence Index for open-weight models. Models with a published index use it; a few local models that AA has not indexed get a clearly marked ~ estimate so they can still be compared. One highest-scoring thinking level is kept per model family. A quant is scored as base score × measured accuracy retention. The percentage above a bar is the score lost to quantization.

Size

Weight sizes are derived from each model's parameter groups (dense, routed experts, Engram tables) and effective bits per weight. Base sizes match the published safetensors byte totals; quant sizes match the published GGUF or safetensors download sizes.

Offloading

MoE models only need the active experts resident. With SSD offload the full expert table lives on SSD and active experts stream in. Engram lookup tables can live on SSD independently. Engram currently applies to DeepSeek V4.1 Flash.

Accuracy

Where providers publish top-1 agreement, KL-divergence tables, or benchmark retention (including NVIDIA's NVFP4 evaluation), those measured values are used. Other quants use a conservative curve by quant class and are marked as estimated in the tooltip.

Sources: Artificial Analysis · Hugging Face · Unsloth Dynamic GGUFs · NVIDIA NVFP4. Sizes are decimal GB.
